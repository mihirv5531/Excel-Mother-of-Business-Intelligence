## 🔎 Lookup & Reference Functions

One of the major parts of this project was understanding how Excel can efficiently retrieve information from large datasets.

### VLOOKUP

Used to search for a value vertically and return corresponding information from another column.

```excel
=VLOOKUP(lookup_value, table_array, col_index_num, FALSE)
```

### INDEX + MATCH

Explored as a more flexible alternative to traditional VLOOKUP.

```excel
=INDEX(return_range, MATCH(lookup_value, lookup_range, 0))
```

This combination is particularly useful when:

- The lookup column is not the first column
- Data needs to be retrieved from columns to the left
- More flexible lookup logic is required

### Other Lookup Concepts

- `MATCH()`
- `INDEX()`
- Exact vs. approximate matching
- Multi-condition lookups
- Lookup-based data validation
